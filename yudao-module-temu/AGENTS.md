# yudao-module-temu 开发约束

## 修改范围

- 本次任务只允许修改 `yudao-module-temu/` 目录及其子目录中的文件。
- 不得修改仓库其他目录、根目录配置、公共模块或前端代码。
- 如需求必须涉及模块外文件，应先停止并向用户确认，不得自行扩大修改范围。

## 注释要求

- 新增或修改的程序方法、函数必须添加简洁、准确的注释，说明用途、关键参数、返回值和重要副作用；Java 方法优先使用 Javadoc。
- 对复杂业务规则、分支判断、数据转换、并发处理、异常处理和非直观实现，必须在代码内部增加必要注释，说明原因或约束。
- 注释应解释“为什么”以及业务含义，避免对显而易见的代码添加无意义的逐行注释。
- 修改已有方法时，如果该方法缺少必要注释，应一并补充；不要求为未涉及的代码进行无关的批量注释整理。
- 注释使用与当前文件一致的语言；本模块新增代码默认使用中文注释，技术名词和标识符保持原文。
